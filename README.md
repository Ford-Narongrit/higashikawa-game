# HIGASHIKAWA GAME

ระบบเกมงานคริสต์มาส 25 ธ.ค. 2026 — Next.js + Supabase + Vercel
รายละเอียดสเปกทั้งหมดอยู่ใน `CLAUDE.md`

## เริ่มพัฒนาบนเครื่อง

```bash
npm install
cp .env.example .env.local   # แล้วใส่ค่าจริง
npm run dev                  # http://localhost:3000
```

ตรวจว่าตั้งค่าครบ: เปิด `http://localhost:3000/api/health` ทุกช่องต้องเป็น `true`

## ฐานข้อมูล

SQL อยู่ใน `supabase/migrations/` — รันตามลำดับชื่อไฟล์ใน Supabase Dashboard → SQL Editor

## หน้าต่างๆ

| URL | ใช้ทำอะไร |
|---|---|
| `/` | หน้าผู้เล่น (มือถือ) |
| `/box/ABC234` | QR บนกล่อง → เปิดหน้าผู้เล่นพร้อมรหัส |
| `/admin` | ควบคุมงาน (ต้องล็อกอิน) |
| `/screen` | จอเวที — ดับเบิลคลิกเพื่อเต็มจอ, คลิก 🔇 ครั้งแรกเพื่อเปิดเสียง |
| `/admin/boxes/print` | หน้าพิมพ์ QR กล่อง |
| `/screen/tree-test?n=450` | ทดสอบต้นไม้ 3D ด้วยรูปปลอม + FPS |
| `/api/health` | ตรวจการตั้งค่า |

## สคริปต์

| คำสั่ง | ทำอะไร |
|---|---|
| `npm run load-test` | ทดสอบโหลดกับ URL จริง (ดูตัวเลือกในไฟล์ `scripts/load-test.ts`) แล้วลบข้อมูลทดสอบเอง |
| `npm run load-test -- --clean` | ลบผู้เล่น `LT-…` ที่ค้างจากการทดสอบ |
| `npm run demo:scores` | ส่งคะแนนปลอมเพื่อดูแอนิเมชันกระดานคะแนน (`-- flood`, `-- clean`) |
| `npm run purge-photos` | ลบรูปทั้งหมด (หลังงาน) |

**เช้าวันงาน (ที่ยิม)**
- [ ] **Wi-Fi ในยิม**: เอามือถือต่อ Wi-Fi แล้วเปิด `https://<project-ref>.supabase.co/auth/v1/health`
      ต้องเห็น `{"message":"No API key found..."}` ถ้าโหลดค้าง แปลว่า Wi-Fi บล็อก Supabase
      → ส่งรูป**ใช้ไม่ได้** (อัปโหลดตรงไป Supabase) และ realtime ใช้ไม่ได้ (แต่คะแนน/ทีมยังอัปเดตทุก 5–10 วิผ่าน Vercel)
      → ขอ IT ให้อนุญาต `*.supabase.co` หรือประกาศให้ใช้เน็ตมือถือ
- [ ] **DNS ของ Mac**: System Settings → Wi-Fi → Details → DNS ควรเป็นอัตโนมัติ
      (เคยเจอ 1.1.1.1 / 8.8.8.8 ถูกบล็อกในบางเครือข่าย ทำให้ต่อ Supabase ไม่ได้)
- [ ] เปิด 2 หน้าต่าง: `/screen` บนโปรเจกเตอร์ (ดับเบิลคลิกเต็มจอ, คลิก 🔇 เปิดเสียง) และ `/admin` บนจอ Mac
- [ ] ปิดการแจ้งเตือน/โหมดพักหน้าจอของ Mac (System Settings → Lock Screen → ไม่ปิดจอ), เปิด Focus "ห้ามรบกวน"
- [ ] ตั้ง `/admin` → จอเวที = **QR เข้าร่วม**, ปิดกล่อง, ปิดส่งรูป

**ระหว่างงาน**
| คาบ | ทำอะไรใน `/admin` |
|---|---|
| 1 | จอเวที = QR → รอคนเข้าครบ → **เปิดเผยทีม** (ยืนยัน 2 ครั้ง) → จอเวที = ทีม → เปิดส่งรูป |
| 2 | จอเวที = คะแนน → กดปุ่มลัด ゲーム1 แต่ละทีม → กด "เพิ่มคะแนน" |
| 3 | เหมือนคาบ 2 ด้วย ゲーム2 · ตรวจรูประหว่างพัก (คีย์ A / X) |
| 4 | เปิดระบบกล่อง → จอเวที = คะแนน → ปิดกล่อง → **Export คะแนน** → จอเวที = ต้นไม้ 3D → ถ่ายรูปรวม |

**ถ้ามีปัญหา**
- ผู้เล่นกลับเข้าไม่ได้ → `/admin` ค้นชื่อ → **รีเซ็ต PIN** → บอก PIN ใหม่
- คนไม่มีมือถือ → `/admin` → เพิ่มผู้เล่น
- ระบบล่มทั้งหมด → กด **Export คะแนน** (หรือใช้ข้อความล่าสุดที่ export ไว้) แล้วนับต่อบนไวท์บอร์ด
